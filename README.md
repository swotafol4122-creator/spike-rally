# スパイク・ラリー　6人制 戦術バレー（アプリ版）

スマホのホーム画面に追加して、アプリとして遊べるバレーボールゲームです。一度開けば、オフラインでも動きます。

## 入っているファイル（すべてリポジトリの一番上に置く）

- `index.html` … ゲーム本体
- `manifest.json` … アプリの名前・アイコン・横画面の設定
- `sw.js` … オフラインで動かすための仕組み
- `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` / `apple-touch-icon.png` … アイコン

## 公開してアプリにする

1. GitHubのリポジトリで「Add file」→「Upload files」を開き、上のファイルをまとめてアップロードして Commit（前の `index.html` は上書き）
2. Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/(root)` にして Save（設定済みならそのまま）
3. 数分待ってから、スマホで `https://ユーザー名.github.io/リポジトリ名/` を開く
4. Android（Chrome）：ホームの「アプリとして入れる」をタップ。出ないときはChromeのメニューの「アプリをインストール」か「ホーム画面に追加」
5. iPhone（Safari）：共有ボタン →「ホーム画面に追加」
6. ホーム画面のアイコンから起動すると全画面になります（Androidは横画面で固定）

## 更新するとき

新しいファイルを同じ名前で上書きアップロードするだけです。ネットにつながった状態でアプリを開き直すと、新しい版になります。

## ゲームの内容

- 大会に挑戦：市民大会からクラブ世界一決定戦まで8大会。勝つとGPがもらえ、次の大会に進めます
- ゲームプラン：スタメン7人（リベロ含む）と作戦（攻撃スタイル・サーブの狙い・ブロック・レシーブ陣形）を決める
- スカウトと育成：GPで選手を獲得。試合に出た選手はレベルアップ
- 試合：サーブのコース、トスの配球、スパイクのコースとタイミング、ブロックを自分で決める。試合後に選手評価・MVP・チーム成績

## 注意

- 選手データや設定は、その端末のブラウザの中に保存されます
- iPhoneでは、Safariで遊んだデータとホーム画面のアプリのデータは別々に保存されます
